# Code of conduct

This project is for everyone who works with visual regression testing, whatever tool they use. We want it to stay welcoming and useful.

## Expected behavior

- Be respectful and assume good faith.
- Give and accept feedback on the work, not the person.
- Stay neutral about tools: a fair comparison or a missing converter is a contribution, not an attack on a project.

## Unacceptable behavior

- Harassment, insults, discrimination or personal attacks.
- Publishing someone else's private information.
- Spam, or promoting a product in places where it is off topic.

## Scope and enforcement

This applies to the repository, its issues, pull requests and discussions, and the visual-regression.dev site. Maintainers may edit or remove comments, and lock threads or block users who do not follow this code.

To report a problem, use [private vulnerability reporting](https://github.com/visual-regression/visual-regression/security/advisories/new) on this repository and say that it is a conduct report. Only the maintainers can see it.
