[Why screenshots flake](/learn/why-screenshots-flake) explains where the noise in a visual test comes from. This cookbook is the hands-on counterpart: one recipe per cause, each with the symptom you see in the diff, the fix as code for the runners most teams use, and a way to prove the flake is gone.

Every recipe has the same shape:

- **Symptom**: what the diff image looks like when this is your problem.
- **Fix**: concrete code for Playwright (`toHaveScreenshot`), Cypress with [`@pixsame/cypress-plugin-visual-regression-diff`](https://github.com/pixsame/pixsame/tree/main/packages/cypress-plugin-visual-regression-diff), Vitest browser mode (`toMatchScreenshot`) and, where one exists, a framework-agnostic approach that works with BackstopJS, Storybook or any other tool.
- **Verify**: how to show the test is stable now, usually by running it repeatedly.
- **See also**: the chapter, the docs and the neighboring recipes.

The recipes are ordered the way the [learn chapter](/learn/why-screenshots-flake#the-order-to-try-things) recommends trying things: remove the noise at the source first, mask what is left, and touch the threshold last.
