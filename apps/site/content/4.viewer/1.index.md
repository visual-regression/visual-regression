Pick the folder a run left behind (the one that holds `visual-regression-manifest.json` and the screenshots, usually the project root or an unpacked CI artifact) or drop the files here. A zip of it works too, such as the artifact as your CI downloads it, so there is no need to unpack it. Everything stays in your browser: the page reads the manifest, matches the image paths to the files you dropped, and shows baseline, actual and diff side by side.

:manifest-viewer

## What it shows

The entries that need a human come first: `failed` and `missing-baseline`. Each one shows the baseline and the actual image with a slider, the diff image when the tool wrote one, the diff ratio against the maximum diff ratio and the colour tolerance when the writer recorded them, and where the test lives. Passed, created, updated and approved entries are listed below for completeness.

Merged runs work too: drop several manifests of one run (one per machine, one per worker) and the viewer merges them the way `mergeManifests` does, later CI attempts winning over earlier ones.

## Zip files and links

A zip can be dropped, chosen with "or choose a zip", or loaded from an address: type it into the field, or link straight to it.

- `https://visual-regression.dev/viewer?zip=https://example.com/run.zip` loads the zip when the page opens. Repeat `zip` to merge several zips of one run.
- `https://visual-regression.dev/viewer#zip=https://example.com/run.zip` does the same, and the address after `#` never reaches this site's server. Prefer it when the address carries a secret, such as a signed URL.

Your browser fetches the zip, with no cookies or credentials, so the server that hosts it has to allow cross-origin requests (`Access-Control-Allow-Origin`). Storage that is open to the public usually does; a GitHub Actions artifact does not, because its download needs a login: download it and drop the zip instead. The zip is unpacked in the browser (up to 1 GiB), nothing is uploaded.

## Running it yourself

The same viewer ships as a package, for runs on your machine and for CI artifacts you unpacked:

```bash
npx visual-regression-viewer path/to/run
npx visual-regression-viewer artifact.zip
```

It reads every manifest below the folder (or in the zip, which is unpacked to a temporary folder that is removed when the command stops), merges them and serves the viewer at `http://127.0.0.1:4173`, with nothing written to disk. `-o report` writes the page and its images to a folder that opens from the file system or any static host, and reloads the page when that folder changes. The [command line page](/viewer/cli) lists every option, the CSS variables that restyle the page and how to replace the page with your own.
