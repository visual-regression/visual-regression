Pick the folder a run left behind (the one that holds `visual-regression-manifest.json` and the screenshots, usually the project root or an unpacked CI artifact) or drop the files here. Everything stays in your browser: the page reads the manifest, matches the image paths to the files you dropped, and shows baseline, actual and diff side by side.

:manifest-viewer

## What it shows

The entries that need a human come first: `failed` and `missing-baseline`. Each one shows the baseline and the actual image with a slider, the diff image when the tool wrote one, the diff ratio against the maximum diff ratio and the colour tolerance when the writer recorded them, and where the test lives. Passed, created, updated and approved entries are listed below for completeness.

Merged runs work too: drop several manifests of one run (one per machine, one per worker) and the viewer merges them the way `mergeManifests` does, later CI attempts winning over earlier ones.

## Running it yourself

The same viewer ships as a package for CI artifacts and offline review:

```bash
npx visual-regression-viewer path/to/run
```

writes a static `index.html` next to the manifest that works from the file system, without a server. It is in preparation; the page above is the first implementation.
